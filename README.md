# Homework 1: Health Tracker and Agent Skills

This repository contains my first AI Bootcamp homework. I built a full-stack health tracker, then used a feature branch to develop a GitHub repository analysis skill for an AI agent.

## Where to look

| Branch | What it contains |
| --- | --- |
| [`main`](https://github.com/vovcik007/Teamvoy_AI_Bootcamp_hw1/tree/main) | The health tracker: a React and TypeScript frontend, a FastAPI backend, and SQLite storage. |
| [`feature/ai-cli`](https://github.com/vovcik007/Teamvoy_AI_Bootcamp_hw1/tree/feature/ai-cli) | The health tracker plus the published repository analyzer skill, examples, and a [detailed README](https://github.com/vovcik007/Teamvoy_AI_Bootcamp_hw1/blob/feature/ai-cli/README.md). |

The tracker records daily water intake, meals, sugar, sleep, work hours, and mood. It shows recent logs and summary statistics. Start with [`frontend/`](frontend/) for the interface and [`backend/`](backend/) for the API. The skill's instructions and scripts are on `feature/ai-cli` under [`.agents/skills/github-repo-analyzer`](https://github.com/vovcik007/Teamvoy_AI_Bootcamp_hw1/tree/feature/ai-cli/.agents/skills/github-repo-analyzer).
